# GAA Sub Planner

A one-page planner for underage hurling and gaelic football coaches: keep a panel, tick who's here, set the formation, and get a fair substitution plan by quarter.

**Open it:** https://nmmh.github.io/gaa-planner/

- Everything is stored on your own phone (browser storage). No player data is uploaded or kept in this repository.
- **📲 Send** creates a link that loads the whole setup (panel, attendance, formation, subs) on another mentor's phone.
- **Load ClubZap RSVP report** reads a ClubZap RSVP `.csv` to build the panel or tick who's coming.

To update the app, replace `index.html` and push to `main`.

## Versions

The version shown at the bottom of the page links to its commit here. Each release is tagged (`v1.0`, `v1.1`, …).

- **v1.1** — Your adjustments get their own section (with Undo / Undo all); Substitutions shows only what happens at each break. Version number on the page.
- **v1.0** — First version: panel, attendance, ClubZap RSVP import, equal-time quarters, tap/drag swaps, send to another phone.
